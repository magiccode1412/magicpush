# 飞牛 NAS 应用商店安装

MagicPush 已上架[飞牛NAS](https://www.fnos.com/)应用商店，支持一键安装部署。

## 安装步骤

1. 打开飞牛NAS管理界面
2. 进入 **应用商店**
3. 搜索 `MagicPush` 或 `魔法推送`
4. 点击安装即可

> 安装完成后访问 `http://<NAS IP>:818` 即可进入管理后台

## 接入飞牛系统通知

安装好 MagicPush 后，可以把飞牛OS（fnOS）的系统通知转发到你绑定的推送渠道，只需 4 步：

### 1. 新增接口

进入 MagicPush 管理后台的「接口管理」，点击「新建接口」：

- 填写名称，例如 `飞牛系统通知`
- 勾选要接收消息的渠道（企业微信、Telegram 等）
- 保存后系统会自动生成访问令牌

### 2. 开启入站配置

在刚创建的接口卡片上点击「入站配置」，打开「启用入站接收」开关。

![入站配置](/image/对接飞牛系统通知1.webp)

### 3. 选择飞牛OS 预配置

**v1.14.0（当前）**

在「数据来源类型」中选择 **通用**，标题字段填入`$.title`，内容字段填入`$.body`即可

**v1.14.1发布后**

在「数据来源类型」中选择 **飞牛OS**。

这是系统内置的预设模板，字段映射（`title` / `body`）已自动处理，无需手动填写。想自定义格式可改为「通用」模板，详见[入站配置指南](/guide/api/inbound-config)。

附上飞牛通知的请求体示例：

```json
{
    "eventId":"webhook-test-1792151841175",
    "providerType":"",
    "providerId":"",
    "eventType":"",
    "occurredAtMs":0,
    "level":"normal",
    "title":"test-测试推送",
    "body":"设备名称：vm-fnos\n触发告警：test-测试推送\n告警详情：这是一条测试消息。\n触发时间：2026-10-16 19:57:21 +08:00",
    "data":null
}
```

### 4. 把接收地址填入飞牛

复制入站配置面板底部显示的**接收地址**：

```
http://<NAS IP>:818/api/inbound/<你的令牌>
```

然后回到飞牛OS 管理界面，进入「系统设置 → 系统通知 → Webhook 机器人」，其他机器人粘贴该地址保存即可。

配置完成后，可以点击飞牛通知设置里的「测试」按钮，或在 MagicPush 入站配置面板中使用「发送测试请求」验证是否收到消息。

![2](/image/对接飞牛系统通知2.webp)

> 如果不方便把令牌放在 URL 中，也可以把令牌填入配置项`密钥`中，地址则使用 `http://<NAS IP>:818/api/inbound`。

![3](/image/对接飞牛系统通知3.webp)

## 更新说明

⚠️ 由于飞牛NAS应用商店需要经过平台审核，**新版本发布后会有一定的延迟**才能在应用商店中看到更新。

如需第一时间体验最新版本，建议使用 [Docker 部署](/guide/deploy/docker)方式。
