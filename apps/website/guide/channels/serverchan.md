# Server酱 推送渠道配置指南

本教程将指导你如何在 MagicPush（魔法推送）中配置 **Server酱** 推送渠道，实现向微信推送消息通知。

## 概述

### 什么是 Server酱？

Server酱是一个消息推送服务，可以将消息推送到微信。目前有两个版本：

| 版本 | 官网 | 说明 |
|------|------|------|
| **Turbo 版（SCT）** | [sct.ftqq.com](https://sct.ftqq.com/) | 最新版，功能更丰富 |
| **³版（SC3）** | [sc3.ft07.com](https://sc3.ft07.com/) | 经典版，接口简单 |

> 💡 **推荐**：新用户建议直接使用 **Turbo 版**，功能更完整。

### 两个版本对比

| 对比项 | Turbo 版（SCT） | ³版（SC3） |
|--------|-------------------|---------------
| 推送目标 | 微信（可指定渠道） | 微信 |
| SendKey 格式 | `SCTxxxxxx...` | `sctpxxxxxxT...` |
| 消息格式 | text、markdown、html | text、markdown |
| 额外功能 | 指定推送渠道、抄送、隐藏 IP | 标签分类 |
| 配置复杂度 | 中 | 低 |

### 前置条件

- 拥有微信号（用于接收推送）
- 已注册 Server酱账号（Turbo 版或 ³版）
- 已部署并登录 MagicPush 管理后台

## 第一步：获取 SendKey

### 方式一：Turbo 版（推荐）

1. 访问 [Turbo 版官网](https://sct.ftqq.com/)
2. 点击 **「登录」**，使用微信扫码登录
3. 登录后，在首页可以看到 **「SendKey」**
4. 点击 **「复制」** 按钮，复制 SendKey（格式为 `SCTxxxxxx...`）

> 📌 **Turbo 版 SendKey 格式**：以 `SCT` 开头，如 `SCTabcdEFGHIJKLMnopQRSTUVwxyZ`

### 方式二：³版

1. 访问 [³版官网](https://sc3.ft07.com/)
2. 点击 **「登录」**，使用微信扫码登录
3. 登录后，在首页可以看到 **「SendKey」**
4. 点击 **「复制」** 按钮

> 📌 **³版 SendKey 格式**：以 `sctp` 开头，后接数字和字母，如 `sctp12345Tabcdefghijklmn`

至此，你已获得配置所需的信息：

| 配置项 | 示例值 | 来源 |
|--------|--------|------|
| SendKey | `SCT...` 或 `sctp...T...` | Server酱控制台首页 |

## 第二步：在 MagicPush 中添加渠道

### 2.1 进入渠道管理

1. 登录 MagicPush 管理后台（默认地址 `http://<服务器IP>:3000`）
2. 点击左侧导航 **「渠道管理」**
3. 点击右上角 **「+ 绑定渠道」** 按钮

### 2.2 选择渠道类型

在弹出的对话框中，从渠道类型下拉列表中选择 **「Server酱」**。

### 2.3 填写配置信息

根据使用的版本，填写以下配置字段：

#### Turbo 版配置

| 字段 | 说明 | 示例 |
|------|------|------|
| **版本** | 选择「Turbo版 (SCT)」 | `Turbo版 (SCT)` |
| **SendKey** | 从 Turbo 版控制台复制 | `SCTabcd...` |
| **推送渠道**（可选） | 指定推送渠道编号 | `9`（Android） |
| **抄送 OpenID**（可选） | 消息抄送的 openid | `openid1,openid2` |
| **隐藏调用 IP**（可选） | 是否隐藏调用者 IP | 开关 |

> 💡 **推送渠道说明**（Turbo 版专属）：
> - `9` = Android 渠道
> - 留空使用默认渠道
> - 在 Server酱 控制台中可以查看所有渠道编号

#### ³版配置

| 字段 | 说明 | 示例 |
|------|------|------|
| **版本** | 选择「³版 (SC3)」 | `³版 (SC3)` |
| **SendKey** | 从 ³版控制台复制 | `sctp12345T...` |
| **标签**（可选） | 消息分类标签，竖线分隔 | `服务器报警\|报告` |
| **简短描述**（可选） | 消息卡片中的简短描述 | `CPU 告警` |

填写完成后，给渠道起一个易于辨识的**名称**（如「Server酱微信推送」），点击 **「保存」**。

### 2.4 测试连通性

渠道创建成功后，在渠道卡片右侧的下拉菜单中，点击 **「测试」** 按钮。

- ✅ 如果微信收到「这是一条来自魔法推送的测试消息」，说明配置成功
- ❌ 如果测试失败，请参考下方[常见问题](#常见问题)排查

> 💡 **提示**：微信接收消息可能有 1-2 分钟延迟，请耐心等待。

## 第三步：使用推送

### 3.1 通过 API 推送

创建渠道后，可以通过 MagicPush 的标准 API 进行推送：

```bash
curl -X POST http://<服务器IP>:3000/api/push/<渠道ID> \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <你的API Token>" \
  -d '{
    "title": "系统告警",
    "content": "服务器 CPU 使用率超过 90%，请及时处理",
    "type": "markdown"
  }'
```

支持的消息类型（`type` 参数）：

| type 值 | 说明 |
|---------|------|
| `text` | 纯文本消息（默认） |
| `markdown` | Markdown 格式消息 |
| `html` | HTML 格式消息（仅 Turbo 版支持） |

### 3.2 Markdown 消息示例

Server酱支持以下 Markdown 语法：

```markdown
## 系统告警通知

**服务器**：192.168.1.100
**告警级别**：<font color="warning">高</font>

> 时间：2024-06-01 14:00
> CPU使用率：95%

[查看详情](https://monitor.example.com/alert/12345)
```

## 技术细节

### 消息长度限制

- 消息内容：最长不超过 **50000 字符**

### 频率限制

- Turbo 版：免费用户 **200 条/天**，付费版更高
- ³版：免费用户 **200 条/天**，付费版更高

### Turbo 版额外功能

| 参数 | 说明 |
|--------|------|
| `channel` | 指定推送渠道（如 `9` = Android） |
| `openid` | 抄送 OpenID，多个用逗号或竖线分隔 |
| `noip` | 是否隐藏调用者 IP（`1` = 隐藏） |

## 常见问题

### Q: 发送消息返回「SendKey 无效」错误？

**原因**：SendKey 填写错误，或版本选择错误。

**解决**：
1. 检查 SendKey 是否完整复制，没有多余空格或换行
2. 确认版本选择正确（Turbo 版 SendKey 以 `SCT` 开头，³版以 `sctp` 开头）
3. 重新从 Server酱 控制台复制 SendKey

### Q: ³版 SendKey 格式错误？

**原因**：³版 SendKey 格式为 `sctp{uid}T...`，需要包含 `T`。

**解决**：
1. 确认 SendKey 格式为 `sctpxxxxxxT...`
2. 中间的 `{uid}` 是数字，后面的部分是随机字符串
3. 完整复制，不要只复制部分

### Q: 微信没有收到推送消息？

**原因**：可能有多种情况。

**解决**：
1. 确认微信关注了 Server酱 公众号
2. 检查是否开启了消息通知（微信设置 → 新消息通知）
3. 消息可能有 1-2 分钟延迟，请耐心等待
4. 检查 Server酱 控制台，查看消息发送记录

### Q: 提示「超过每日限制」？

**原因**：免费版每天限制 200 条消息。

**解决**：
1. 升级到付费版（在 Server酱 控制台中升级）
2. 降低推送频率，合并多条消息为一条
3. 使用其他推送渠道（如企业微信、钉钉等）

### Q: Turbo 版和 ³版可以同时使用吗？

**回答**：可以。在 MagicPush 中分别创建两个渠道，一个选择 Turbo 版，一个选择 ³版。

### Q: 如何指定推送到特定设备？

**解决**（仅 Turbo 版）：
1. 在配置中填写 **「推送渠道」** 字段
2. 渠道编号在 Server酱 控制台 → 推送渠道中查看
3. `9` 通常对应 Android 渠道
