# 隐私政策

**最后更新日期：2026年6月22日**

## 核心声明

**MagicPush（魔法推送）不会收集用户的任何个人数据。**

MagicPush 是一款开源的消息推送服务管理平台，采用**完全自部署**架构。这意味着：

- **所有数据存储在您自己的服务器上**
- **项目开发者无法访问您的任何数据**
- **不存在远程数据收集机制**
- **没有用户行为分析或追踪**

---

## 1. 关于 MagicPush 的数据架构

### 1.1 完全本地化部署

MagicPush 采用 Docker 或直接部署的方式运行在您自己的服务器、NAS 或云实例上。整个系统由以下组件组成：

| 组件 | 数据存储位置 | 谁可以访问 |
|------|-------------|-----------|
| 后端服务 (server) | 您的服务器 | 仅您 |
| 前端界面 (web) | 您的浏览器 | 仅您 |
| 数据库 (SQLite) | 您的服务器本地文件 | 仅您 |
| 日志文件 | 您的服务器本地 | 仅您 |

### 1.2 无远程通信的数据收集

MagicPush 与外部服务的唯一交互是通过您**主动配置**的第三方推送渠道（如企业微信、Telegram 等）发送消息。除此之外，系统**不会向任何远程服务器发送您的使用数据**。

---

## 2. 我们不收集的信息

MagicPush 项目本身**不会收集**以下任何信息：

| 信息类型 | 说明 |
|---------|------|
| 个人身份信息 | 姓名、身份证号、联系方式等 |
| 使用行为数据 | 登录次数、功能使用频率、操作记录等 |
| 设备信息 | IP 地址、设备型号、浏览器指纹等 |
| 消息内容 | 推送消息的标题和正文内容（仅存于您的本地数据库） |
| 渠道配置 | 您填写的 API Key、Token 等敏感信息 |

> **注意：上述信息可能以加密形式临时存储在您自己的数据库中，用于正常提供服务（如账户登录、渠道配置保存），但绝不会传输到项目开发者或任何第三方服务器。**

---

## 3. 数据的真正去向

### 3.1 存储在您的控制范围内

当您使用 MagicPush 时：

- **账户信息** → 存储在您部署的 SQLite 数据库中
- **渠道配置** → 存储在您部署的 SQLite 数据库中
- **推送记录** → 存储在您部署的 SQLite 数据库中
- **系统日志** → 输出到您服务器的日志文件中

这些数据**完全由您掌控**。

### 3.2 发送到第三方推送渠道

唯一的外部数据传输发生在您**主动触发推送时**：

```
您的服务器 → 第三方平台（如企业微信/Telegram）
     ↓
   消息内容仅发送到您配置的目标渠道
```

这是您**明确授权的行为**，数据直接从您的服务器发送到您选择的接收端，不经过任何中间服务器。

## 5. 您的责任与权利

### 5.1 数据安全责任

由于 MagicPush 是自部署软件，**您对自己的数据安全负全部责任**：

- 保护好服务器访问权限
- 定期备份数据库文件
- 使用强密码保护管理员账户
- 如使用公网部署，建议启用 HTTPS

### 5.2 完全的数据主权

您享有以下权利：

| 权限 | 说明 |
|------|------|
| 访问权 | 直接查询本地数据库即可获取所有数据 |
| 修改权 | 通过管理界面或直接编辑数据库修改数据 |
| 删除权 | 删除数据库文件即可永久清除所有数据 |
| 迁移权 | 备份数据库后可随时迁移到其他服务器 |
| 导出权 | 管理界面支持导出配置为 JSON 文件 |

## 6. 第三方推送渠道说明

MagicPush 本身不收集数据，但当您配置并使用第三方推送渠道时，这些渠道可能有各自的数据处理政策：

| 渠道 | 提供方 | 建议 |
|------|--------|------|
| 企业微信 | 腾讯 | 阅读腾讯隐私政策 |
| Telegram | Telegram FZ-LLC | 阅读Telegram隐私政策 |
| 飞书 | 字节跳动 | 阅读字节跳动隐私政策 |
| 钉钉 | 阿里巴巴 | 阅读阿里巴巴隐私政策 |
| PushPlus / Server酱 等 | 各自运营方 | 阅读相应平台的隐私政策 |

**重要提示：通过这些渠道发送的消息内容由各渠道自行处理，与 MagicPush 项目无关。**
