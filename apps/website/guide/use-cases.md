# 应用场景

MagicPush 作为一款支持 20+ 渠道的统一推送平台，适用于多种行业和使用场景。以下是按领域分类的典型应用案例。

## 运维监控（DevOps / SRE）

### 服务器告警通知

将 Grafana、Prometheus、Zabbix 等监控系统的告警实时推送到运维人员的手机或即时通讯工具。

| 配置项 | 推荐方案 |
|-------|---------|
| **数据来源** | Grafana / Prometheus AlertManager |
| **入站模板** | 选择「Grafana」或「Prometheus」预设模板 |
| **关键词过滤** | 白名单模式，只放行包含 `Critical`、`P0`、`DOWN` 的消息 |
| **免打扰配置** | 工作日白天正常推送，夜间 `22:00~08:00` 仅接收 P0 级别告警 |

**效果**：凌晨 3 点的服务器 CPU 告警不再吵醒你，但核心服务宕机的紧急通知依然能送达。

### CI/CD 构建状态推送

将 GitHub Actions、GitLab CI、Jenkins 的构建结果推送到团队群。

| 配置项 | 推荐方案 |
|-------|---------|
| **数据来源** | GitHub Webhook（Push / PR / Issue 事件）|
| **入站模板** | 选择「GitHub」预设模板 |
| **关键词过滤** | 无需过滤，全部放行 |

**效果**：代码合并后自动在群里收到构建结果通知，无需手动刷新页面。

### 批量服务器健康巡检

定时脚本检查多台服务器状态，通过 MagicPush 汇总推送。

```bash
#!/bin/bash
# 示例：通过 API 推送巡检结果
curl -X POST "https://your-magicpush/api/push/YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "每日巡检报告",
    "content": "✅ web-01: 正常\n⚠️ web-02: 磁盘使用率 85%\n❌ db-01: MySQL 连接数超限",
    "type": "text"
  }'
```

## 个人效率工具

### 个人任务提醒

配合 cron 定时任务或脚本，将待办事项、日程提醒推送到手机。

| 场景 | 示例 |
|------|------|
| **喝水提醒** | 每 2 小时推送一次 |
| **会议提醒** | 日历事件提前 15 分钟推送 |
| **账单到期** | 每月 1 号提醒信用卡还款 |
| **习惯打卡** | 每晚 22:00 推送"今日运动完成了吗？" |

```bash
# crontab 示例：每 2 小时喝水提醒
0 */2 * * * curl -X POST "https://your-magicpush/api/push/YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "💧 喝水提醒", "content": "该喝水了！保持健康", "type": "text"}'
```

### 价格监控与抢购通知

监控商品价格变动或库存状态，第一时间推送通知。

| 场景 | 说明 |
|------|------|
| **商品降价** | 脚本定期抓取价格，低于阈值即推送 |
| **补货提醒** | 缺货商品重新上架时立即通知 |
| **限时优惠** | 监控促销活动开始时间 |

```python
# Python 示例伪代码
if current_price < target_price:
    requests.post("https://your-magicpush/api/push/TOKEN", json={
        "title": "🔥 降价提醒！",
        "content": f"{product_name} 降至 ¥{current_price}",
        "type": "text"
    })
```

## 最佳实践总结

### 合理使用免打扰

1. **区分接口优先级** — 核心业务告警不设免打扰，次要通知设置静默时段
2. **多接口策略** — 将紧急和非紧急消息分别发送到不同接口，独立配置免打扰规则
3. **利用日志回溯** — 被静默的消息仍保留完整日志，第二天可以批量查看夜间遗漏的通知

### 入站配置技巧

1. **善用预设模板** — Grafana/Prometheus/GitHub/Emby 开箱即用
2. **通用模式灵活映射** — 用 JSONPath 提取任意字段组合成自定义格式
3. **先测试再上线** — 使用面板内的测试功能验证效果后再接入真实 Webhook

### 关键词过滤策略

| 策略 | 适用场景 | 示例关键词 |
|------|---------|-----------|
| **黑名单** | 过滤垃圾/广告 | 广告、推广、代购 |
| **白名单** | 只收紧急消息 | Critical、P0、DOWN |
| **来源过滤** | 多源混合时隔离 | Grafana、GitHub |
